# Лор (сюжет и мир)

> Этот раздел пишет **автор мода** (ты). Я отвечаю за механики и реализм;
> здесь — твоя территория. Ниже — формат, чтобы лор было удобно складывать.

## Правила лора (согласованные со столпами дизайна)

1. **Лор свободен, технологии правдоподобны.** Можно придумать любые фракции, катастрофы
   и историю, но техника в лоре должна оставаться реалистичной (см. `docs/design/pillars.md`, п. 6).
2. **Лор объясняет, почему игрок один.** Откуда ресурсы, почему нет готовой инфраструктуры,
   почему вокруг опасно.
3. **Лор задаёт названия.** Имена предметов, машин, мест — из лора. Это помогает погружению.

## Формат: один файл на тему

```
lore/
├── README.md        ← этот файл (правила и навигация)
├── story.md         ← сюжет (отредактирован под реализм)
├── tech.md          ← разбор технологий: реально / гипотеза / допущение
├── factions.md      ← фракции и Игрок
├── timeline.md      ← хронология мира
├── tech_tiers.md    ← (позже) ступени технологий и их ограничения
└── glossary.md      ← (позже) глоссарий терминов
```

## Текущий статус лора

Автор прислал сюжет (Третья мировая → гибель биосферы → криосон Игрока → две фракции
→ финал с выбором на другой планете). Я отредактировал его под реализм, сохранив все
сюжетные ходы:

- `story.md` — полный сюжет;
- `tech.md` — что именно и почему поправлено (оружие судного дня, ядерная зима,
  радиационный тайминг, крионика, механика «оживления» Земли);
- `factions.md` — «Исход» и «Возрождение» + роль Игрока;
- `timeline.md` — хронология.

Единственное крупное художественное допущение сюжета — **Праматерия** (метастабильный
ядерный изомер, см. `tech.md`, п. 1). Всё остальное опирается на реальную физику.

## Шаблон записи (фракция / корпорация / этап)

```markdown
## Название

- **Роль в мире:** (одна строка)
- **Мотивация/цель:** (зачем существует)
- **Технологический уровень:** (какие реальные технологии доступны, какие — нет)
- **Отношение к игроку:** (союзник / враг / нейтрален)
- **Влияние на механики:** (что это меняет в игре — ресурсы, рецепты, ограничения)
```

## Минимальный стартовый набор (предлагаю заполнить первым)

1. **Где и когда** происходит действие (Земля? альтернативная история? после катастрофы?).
2. **Почему игрок строит космическую программу** в одиночку.
3. **Одна-две фракции/структуры**, задающие тон (корпорация, остатки агентства, автономный ИИ...).

Скинь лор текстом — я разложу его по этим файлам и привяжу к реестру контента.
