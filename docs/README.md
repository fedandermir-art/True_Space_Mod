## Ключевые договорённости

1. **Реализм первичен.** Каждая механика опирается на реальный процесс или число с источником.
2. **Хардкор = последствия, а не тоска.** Вакуум, холод и радиация реально убивают, но игра не должна превращаться в бессмысленный гринд.
3. **Мир Minecraft ≠ реальный мир.** Блок = 1 м, время сжато. Реальные числа переносятся через **задокументированные** масштабные коэффициенты (см. `reference/physics.md`), а не «на глаз».
4. **Нет магических блоков.** «Руда → слиток» запрещено. Только реальные процессы: Байер, Холла-Эру, Кролл, электролиз и т.д.
5. **Весь контент — в реестре** (`content/`). Сначала запись с реальной основой, потом код.
