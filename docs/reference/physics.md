# Физико-химический справочник

Это база реальных чисел, на которую опираются все механики мода.
Каждое число здесь — общеизвестный, проверяемый факт (источники: [`realism_sources.md`](realism_sources.md)).

> Как читать: «реальное значение» → «как переносится в игру». Масштабирование всегда документируется.

---

## 1. Ракетное движение

### Уравнение Циолковского

```
Δv = Isp · g₀ · ln(m₀ / m_f)
```

- `Δv` — изменение скорости (м/с) — «бюджет» манёвра;
- `Isp` — удельный импульс (с);
- `g₀` = 9.80665 м/с² (стандартное ускорение свободного падения);
- `m₀` / `m_f` — начальная и конечная масса (массовое отношение).

**Следствия для геймплея:** Δv растёт логарифмически с запасом топлива.
Чтобы удвоить Δv, нужно *квадрат* массового отношения — поэтому ступени и лёгкие баки важнее
«просто больше топлива». Это станет ядром расчёта ракет в моде.

### Удельный импульс (Isp) реальных двигателей

| Двигатель / пара | Isp у земли | Isp в вакууме |
|---|---|---|
| F-1 (LOX/RP-1, Сатурн-5) | ~263 с | ~304 с |
| Merlin 1D (LOX/RP-1) | ~311 с | ~348 с |
| RD-180 (LOX/RP-1) | ~311 с | ~338 с |
| RS-25/SSME (LOX/LH₂) | ~366 с | ~452 с |
| RL10 (LOX/LH₂) | — | ~465 с |
| Raptor (LOX/LCH₄) | ~330 с | ~380 с |
| Гипергольные (NTO + UDMH/MMH) | — | ~280–340 с |
| Твердотопливные (SRB) | ~240–260 с | ~260–290 с |
| ЯРД NERVA (LH₂) | — | ~850–900 с |
| Ионные (Xe) | — | 2000–4000+ с |

**Правила баланса:**
- Чем выше Isp — тем меньше тяга (ионники — миллиньютоны) и/или дороже/сложнее топливо.
- LH₂ даёт рекордный Isp, но его плотность ~70.85 кг/м³ → огромные баки и выкипание.
- RP-1 плотный и хранимый, но «грязный» (сажа, коксование) и ниже Isp.
- Гиперголики хранятся годами и самовоспламеняются, но токсичны и опасны в обслуживании.

### Бюджет Δv (реалистичные значения)

| Манёвр | Δv |
|---|---|
| Поверхность Земли → НОО | ~9.3–9.7 км/с (с учётом гравитации и атмосферы) |
| НОО → ГПО (геопереходная) | ~2.4–2.5 км/с |
| НОО → ТЛИ (к Луне) | ~3.1–3.2 км/с |
| НОО → поверхность Луны (суммарно) | ~5.7–6.1 км/с |
| Поверхность Луны → НОО (возврат) | ~2.7–3.1 км/с |
| НОО → переходная к Марсу | ~3.6–4.3 км/с |
| НОО → выход из сферы Земли | ~3.2 км/с |

**В игре** расстояния сжаты, поэтому абсолютные км/с масштабируются,
но **относительные пропорции** (Марс требует больше, чем Луна; старт дороже всего) сохраняются.

### Орбитальная механика (основы)

- **НОО** (низкая опорная орбита): ~160–2000 км, период ~88–127 мин.
- **Переход Хомана** — самый экономичный перелёт между круговыми орбитами (два импульса).
- **Эффект Оберта**: манёвр выгоднее в перицентре (у дна гравитационного колодца) —
  геймплейно: жги топливо у планеты, а не в открытом космосе.
- **Наклонение** меняется дорого: смена наклонения на LEO стоит огромных Δv (~2·v·sin(Δi/2)).

## 2. Жизнеобеспечение (реальные нормы человека)

| Параметр | Значение |
|---|---|
| Кислород | ~0.84 кг O₂/чел/сут |
| Вода | ~2.5–3.7 л/чел/сут (питьё + гигиена) |
| Еда | ~0.62 кг/чел/сут |
| Выдох CO₂ | ~1.0 кг/чел/сут |
| Метаболическое тепло | ~100–120 Вт/чел |
| Парциальное давление O₂ | 16–21 кПа (норма ~21 кПа) |
| CO₂ (предел) | < 0.5–1 кПа (иначе головная боль, потеря сознания) |

**Замкнутые циклы (как на МКС, ECLSS):**
- CO₂ + 4H₂ → CH₄ + 2H₂O (реакция Сабатье) — возвращает воду;
- 2H₂O → 2H₂ + O₂ (электролиз) — возвращает кислород;
- Реальная МКС регенерирует >90% воды, но часть всё равно уходит — **полного нуля потерь не бывает**.

**Геймплей:** O₂ расходуется, CO₂ копится (нужен скруббер/Сабатье), вода регенерируется не на 100%.
Скафандр — ограниченный запас на часы, а не вечный.

## 3. Радиация

| Источник/ситуация | Доза |
|---|---|
| Земной фон | ~2.4 мЗв/год |
| НОО (МКС) | ~0.5–1 мЗв/сут |
| Миссия МКС (6 мес) | ~80–160 мЗв |
| Межпланетный перелёт (ГКЛ) | ~0.5 мЗв/сут |
| Поверхность Марса (Curiosity) | ~0.67 мЗв/сут |
| Солнечная вспышка (СПЭ, без укрытия) | до Зв за событие (смертельно) |
| Предел для персонала (год) | 20 мЗв (рекомендуемый) |
| Карьерный предел астронавта | ~600–1000 мЗв (по NASA, зависит от пола/возраста) |

**Единицы:** грей (Гр) — поглощённая доза, зиверт (Зв) — биологический эффект.
Для гамма/рентгена 1 Гр ≈ 1 Зв.

**Защита:** вода и полиэтилен эффективнее алюминия на единицу массы против нейтронов и ГКЛ;
толщина защиты растёт по экспоненте — «идеального щита» нет.

**Геймплей:** радиация накапливается (шкала Зв), даёт эффекты (тошнота → слабость → смерть),
убежище/вода/свинец снижают дозу. Радиационные пояса — зоны с повышенным фоном.

## 4. Тепловой режим и вакуум

- В вакууме нет конвекции и теплопроводности — только **излучение** (закон Стефана–Больцмана, ~T⁴).
- «Температура космоса» ~2.7 К — но это не «холод в привычном смысле»: предмет на солнце
  **нагревается** (равновесная температура зависит от альбедо и площади).
- Реальная проблема в космосе чаще **перегрев** (нужны радиаторы), а не замерзание.
- Разгерметизация: при давлении < ~6.3 кПа вода в теле закипает (предел Армстронга);
  сознание теряется за ~10–15 с. Смерть — не мгновенная, но быстрая.
- Точка кипения падает с давлением: вода кипит при ~0.5 кПа уже при ~0 °C.

**Геймплей:** скафандры и модули требуют и охлаждения, и обогрева; разгерметизация — реальная угроза.

## 6. Константы и коэффициенты масштабирования

| Константа | Значение |
|---|---|
| g₀ (стандарт) | 9.80665 м/с² |
| Скорость звука (воздух, 20 °C) | 343 м/с |
| Атмосферное давление (уровень моря) | 101.325 кПа |
| Плотность воздуха (0 °C) | 1.293 кг/м³ |
| Молярный объём газа (н.у.) | 22.4 л/моль |

**Масштабирование в игре (предварительное, фиксируется в реестре):**
- 1 игровой блок = 1 м (объём 1 м³).
- Энергия: 1 игровая «энергоединица» = 1 кДж (уточняется в фазе 1).
- Время: 1 игровой тик (0.05 с) — процессы сжимаются к игровому темпу, пропорции сохраняются.
